# 项目阶段完成度评估

**评估日期：** 2026-10-01  
**评估对象：** 当前工作区中的 MatFlow 后端 1.1 开发状态  
**计分说明：** 下表是面向产品里程碑的工程判断，不是代码覆盖率；“完成”要求能力存在、接口稳定并有自动化证据。

## 一页结论

MatFlow 已达到“后端平台基座可用”的阶段性里程碑，可以继续在此基础上开发领域工作流。当前并未达到“用户给出任意材料学提示词，系统即可自动研究方法、生成工具、构造复杂 DAG 并可靠产出科学结论”的产品目标。

方向性完成度为：

- 后端平台基座：约 **80%**，阶段性通过；
- 通用材料学智能工作流产品：约 **55%**，仍处于 Alpha；
- EBrick 温变阻抗谱完整验收场景：约 **25%**，尚未闭环。

## 验证记录

在不连接在线模型服务的条件下运行完整测试套件：

```text
Ran 100 tests in 3.003s
OK (skipped=4)
```

4 项跳过项都是需要显式授权的 Jev/LLM 在线测试。测试在受限沙箱中会因 Windows 临时目录权限产生 33 个假错误；在正常权限环境重跑后全部消失，不是代码回归。

现有测试覆盖：

- HTTP 契约、图版本冲突和状态读写；
- 类型继承、端口兼容和图校验；
- 路由候选、多模型共识与失败降级；
- 工作流执行、审核暂停和节点演化；
- XRD/FTIR 声明式 Recipe 的噪声夹具评估与修复；
- Prompt normalize 的配置、模式校验和语言漂移拒绝；
- 配置驱动场景测试与报告脱敏。

## 阶段性里程碑判定

### 已通过：M1 后端基座

满足以下条件：

1. 后端是状态与执行的唯一权威；
2. 客户端通过版本化 HTTP 接口工作；
3. 工作流变更经过类型、拓扑和版本校验；
4. 执行可以留下可追踪结果并在人审点暂停；
5. 模型建议不能直接绕过 Tool 生命周期；
6. 离线回归测试稳定通过。

### 未通过：M2 通用智能规划闭环

尚未同时满足：

1. 可靠读取研究规则文档和混合附件；
2. 从中文复杂请求生成多分支、多汇合 DAG；
3. 发现 Capability Gap 后研究方法并生成可执行 Tool；
4. Tool 经隔离评估、审核和发布后进入 Registry；
5. 使用数据质量门控决定是否运行下游机理分析；
6. 输出方法、参数、证据、不确定性和失败原因。

## 下一阶段建议

下一里程碑建议定义为“EBrick 温变 EIS 单场景闭环”，而不是继续横向添加演示案例。完成标准如下：

1. 支持规则文档作为可读取 Dataset，并将炉程解析成结构化温度程序；
2. 实现 `Cp/G + frequency -> complex impedance` 的单位明确转换；
3. 实现扫描时间到温度的可审计映射；
4. 新增基础完整性、KK/Lin-KK、候选电路比较三个并行诊断分支；
5. 新增质量汇总与自动/人工 Review Gate；
6. 质量通过后才执行 DRT、等效电路分量贡献和绘图；
7. 将整条非单链 DAG 纳入固定数据的端到端验收测试；
8. 将 normalize 作为可回退的派生视图接入规划器，而不是覆盖 Research Request。

在这一里程碑通过前，不应把 MatFlow 对外描述为“可自主完成任意材料学分析”；更准确的定位是“具备可靠控制平面的材料学工作流后端，正在补齐领域执行面”。
