# 阶段性交接文档

本目录存放开发阶段之间使用的状态快照。它与 `docs/` 下的正式说明文档分开管理，内容用于快速交接、定位缺口和安排下一阶段工作，**不是长期规范或稳定接口说明**。

## 使用约定

- 每次评估使用独立的日期目录，避免后续状态覆盖历史判断。
- 每个快照的 `README.md` 是唯一入口；具体能力文件只补充简要问题和下一步。
- 若快照与代码、测试或正式文档冲突，以代码、最新测试和正式文档为准。
- 新一轮评估完成后，应将旧快照标记为“已被替代”；里程碑结束后可整体归档或删除。
