# 05 · TGA：由脱碳失重估算 CaCO₃ 含量

## 目的

验证温度–质量曲线处理、指定失重窗口计算和化学计量换算。

## 输入

`examples/data/05_tga_caco3_content/tga_mass_loss.csv`，含 30–900 °C 的温度和归一化残余质量百分比。

## 操作提示

提交：`在 600–850 °C 的失重步骤中估算样品的 CaCO3 质量分数。`

## 预期结果

- 600 °C 前质量基本为 100%，850 °C 后平台约 91.20%。
- 脱碳质量损失约 8.80 wt%。
- 使用 `w(CaCO3) = w(CO2) × 100.09 / 44.01`，得到约 20.0 wt% CaCO₃（允许 ±0.5 wt%）。
- 结果应显式记录温度窗口和化学计量假设。

## 边界

该换算假定此温区的失重全部来自 CaCO₃ → CaO + CO₂。实际样品需排除其他碳酸盐、挥发物和基线漂移。
