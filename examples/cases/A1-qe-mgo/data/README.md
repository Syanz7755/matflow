# A1 data manifest

The case reuses the packaged fixtures identified by [data-sources.json](../data-sources.json)
instead of duplicating them here. That manifest includes the repository-relative
paths and SHA-256 hashes. They are distributed with this MIT-licensed project;
the original executable, pseudopotential files and a complete independent
reproduction environment are not included.

The stdout is an existing historical reference fixture, not a newly imported
real dataset. No live EBrick source was copied during this milestone. Its
upstream path is a recorded provenance label and has not been revalidated here.
